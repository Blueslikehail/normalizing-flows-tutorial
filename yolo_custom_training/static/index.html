How to Use
  1. Switch to Annotate mode
  2. Click Capture Frame
  3. Click & drag to draw a bounding box
  4. Type a label and click Set
  5. Click Save Frame
  6. Repeat for ~10+ frames per class
  7. Click Start Fine-Tuning
  8. Switch to Inference to test
Labels are stored in YOLO format:
class_id xc yc w h (all normalised 0-1)
